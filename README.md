# Dinner planner

Static web app, no build step. Open `index.html` or serve the folder.

- `index.html` markup
- `styles.css` styles
- `app.js` app logic
- `aisles.js` shopping list aisles and the keyword table that sorts ingredients into them
- `config.js` Firebase web config, gitignored. Copy `config.example.js` and fill it in to enable household sync. Without it the app saves on this device only.
- `firestore.rules` Firestore security rules
